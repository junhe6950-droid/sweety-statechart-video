# 画面：主题、画法、镜头和动效

`film.json` 里加几个字段，就能换一种纸、一种笔、一种卡片和一种镜头。不写就是参考作品的样子：奶油纸、蓝蜡笔、票据卡、图钉。

## 主题 `theme`

| 值 | 名字 | 样子 | 适合 |
|---|---|---|---|
| `crayon`（默认） | 蓝蜡笔 | 奶油纸、钴蓝线、彩色蜡笔排线 | 一切 |
| `pencil` | 钢笔彩铅 | 细深色钢笔线、淡彩铅、暖纸、斜体衬线字（Kevin Serif） | 讲清楚的图解、生意、流程 |
| `night` | 夜读 | 深藏青卡纸、浅色线、油画棒亮色 | 夜里的事、科技、睡前 |
| `kraft` | 牛皮纸 | 牛皮纸、黑白粉笔感、马克笔标题 | 工厂、物流、手艺 |
| `riso` | 孔版 | 蓝、荧光粉、黄三色叠印，略微错位 | 观点、清单、年度回顾 |
| `linen` | 亚麻刺绣 | 亚麻布底，配毛毡卡片和金线箭头 | 手作、纪念、科普收尾 |
| `season:spring` / `summer` / `autumn` / `winter` | 节气 | 按季节换插画主色和纸的冷暖 | 系列、节日 |

- 品牌色：`"brand": ["#0a3d62", "#ff6b35", "#f7c548"]`。最深的色画线和字，最鲜的色当“现在”的粉，第三个当暖色点缀；条件红和完成色会自动跟品牌色拉开。
- 细调：`"theme": {"base": "crayon", "colors": {"paper": "#f4efe2"}, "paper": "grid"}`。纸可以是 `cream`、`kraft`、`grid`（方格本）、`dark`、`news`（旧报纸）、`linen`。
- 颜色的意思是固定的：粉 = 现在，红 = 条件和出错，青绿 = 通过、修好了，灰 = 过去、撤销。`check` 和 `lint` 会查对比度和红绿色弱下能不能分清。
- 每章自动换一组图钉色和框底色。手写的 `pin`、`tint` 优先。

## 卡片的画法 `look`

可以写在整片、一章或一个状态上：`"look": "sign"`。

| 值 | 样子 |
|---|---|
| `ticket`（默认） | 参考作品的票据：锯齿底边、红色小标签、一枚图钉 |
| `note` | 便签：略歪，两条胶带粘着 |
| `sign` | 木牌：木纹，四颗螺丝 |
| `soft` | 圆角卡，颜色跟它所在的那条线一样 |
| `plate` | 铜牌：内框，四颗螺丝 |
| `tag` | 行李吊牌：斜角头，扣眼，一圈绳 |
| `slide` | 玻璃载片：透明玻璃、磨砂标签端、一滴染色样本 |
| `patch` | 毛毡补丁：毛边，里面一圈针脚 |

- 状态的性质 `kind`：`final`（终点，双线框）、`error`（出错，红底撕边）、`wait`（等待，右上角一个小钟）、`undo`（撤销，灰色加一道划线）。
- 父状态画成店面：`"regions": {"look": "shop", "lanes": [{"look": "shop", ...}]}`。它会画出条纹遮阳篷、玻璃橱窗和花槽，里面的子状态配 `note`，像便签贴在橱窗上。

## 箭头 `arrows`

写在整片或一章上。

| 值 | 样子 |
|---|---|
| `line`（默认） | 蜡笔线，箭头顶到卡片 |
| `thread` | 红线，两头都停在离卡片一点的地方（钢笔画的习惯） |
| `pencil` | 普通线，两头停一点 |
| `cord` | 金线，横着缝几针（配 `patch` 和 `linen`） |

单条箭头还可以写：
- `"style": "timer"`：虚线加一个小钟，表示“过了多久”；
- `"style": "async"`：波浪线，表示发出去的消息。

**等的是另一条线**：在“同一时间”的章里，一个条件如果在等另一条线（比如店员这边写 `[锅里没在煮]`），条件的字会用那条线的颜色。条件里写到另一条线的标题或状态名时，会自动认出来；也可以直接写 `"waits": "那条线的 id"`。

## 规则章

- 一章可以写多条规则：

  ```json
  "rules": [{"never": "served", "text": "永远不卖老珍珠"}, {"stuck": false, "text": "店不会卡住"}]
  ```

  旧的 `rule` 照常可用。
- 海报上会多一张图例，列出每条规则：
  - 红线画出来以前，规则前面是 `·`；
  - 红线画出来以后，变成 `✓` 或 `✗`，再加一行“检查器找到的路径”和“查遍多少种情况、多少步”。

  `"legend": false` 关掉，`"legendAt": [x, y]` 指定位置。图例占的地方，排版时已经从空地里扣掉。
- 每条被打破的规则各画一条红线。路径上的卡片描红色双边，箭头底下垫一层浅红。
- **先破后立**：

  ```json
  "rule": {"never": "served", "fix": {"edge": "soggy>served", "if": "出餐检查", "stamp": "修好了"}}
  ```

  然后在讲修复的那一步写 `"fix": true`。这一步会：
  1. 在箭头的字下面补一行绿色的 `[出餐检查]`；
  2. 让红线淡成一道影子；
  3. 让出错的卡片恢复原色；
  4. 在另一块空地上盖一枚绿章。

## 镜头和开合

| 字段 | 作用 |
|---|---|
| `"camera": "push"` | 每一步推近到新卡片（约 1.28 倍），下一步再拉回。单步也能写 `"camera": "push"` 或 `"pull"` |
| `"hook": "一碗面要走几格？"` | 开场先放第一章画完的样子，配这句问题，约 3.4 秒后纸从下往上盖住，从头开始 |
| `"outro": "overview"` | 两章以上默认开启。片尾先扫过所有海报，再退到全景，停在片尾卡上。`false` 关掉 |
| `"episode": 3, "next": "骑手的一天"` | 片尾卡写“系列名 · 第 3 集”和“下一集：……”；不写就是“《片名》完” |
| `"ai_label"` | 有旁白时默认在开头 4 秒显示“旁白由 AI 合成”，片尾卡上再显示一次。`false` 关掉，或写别的字 |
| `"player": {"spotlight": true}` | 聚光：每一步除了当前卡片，其余都暗下来。单步也能写 `"spotlight": true` |
| `"player": {"fade": true}` | 走过的箭头变成铅笔灰，只留当前这一步亮着 |
| `"player": {"type_titles": false}` | 关掉章标题的打字效果 |
| `"happy": ["a", "b", "c"]`（写在一章上） | 主线：沿这几个状态的箭头画成金色、加粗，其余箭头变淡（坏路径仍是红的） |
| `"player": {"lanes": false}` | 关掉“同一时间”章字幕条上方那行各条线的当前状态（默认显示，例如“后厨 · 出餐口有餐　骑手 · 店里等餐”） |
| 状态 `"inset": [x, y, r]` | 显微镜小窗：这个状态亮着时，右下角开一个圆镜头，放大海报上 (x, y) 半径 r 的那一块 |
| 状态 `"mood"` | 这个状态亮着时，整张纸变一点色调：`rain`（冷、灰）、`night`（暗蓝）、`alert`（边缘一圈红，呼吸）、`fixed` 和 `warm`（暖） |
| `"anim_fps": 12` | 插画动作按每秒 12 张走（手绘动画的“一拍二”），和线条的抖动更统一。默认平滑 |
| `"text": {"card": 27, "edge": 22.5}` | 卡片字和箭头字的大小。竖版默认 27 / 22.5（手机上读得清），横版和方版默认 23 / 18.5。旧片子想保持原来的排版，写 23 / 18.5 |

## 动效（自动，不用写）

- **图钉**：新卡片弹出时先压扁再回弹，图钉从上面落下扎进去，卡片挂在图钉上晃两下。
- **粉圈**：像拿蜡笔绕卡片一圈那样画出来。
- **章标题**：每章开始时，大标题一个字一个字打出来；副标题和红色小字随后出现。
- **“同一时间”框**：在第一次进入时才画出来。边框先长出来，底色的排线再一行行铺开，最后标题打出来。
- **盖章**：章从 1.6 倍落下，画面震一下，四周溅几粒墨点。
- **字幕跟读**：有旁白的片子，读过的字变深，还没读的字是灰的。

## 字

- 中文随包带三套 GB2312 常用字子集，都是 OFL 许可：
  - 思源宋体同源的 Noto Serif SC Bold（默认）；
  - 朱雀仿宋（`night`、`linen` 主题）；
  - 霞鹜漫黑（`kraft` 主题）。
- 标题和卡片字有打字机墨迹：边缘略洇，有少许缺墨，跟着线条一起抖。`pencil` 主题用干净的钢笔字。

## 检查画面

`scv.py lint JOB` 逐章检查插画，每条问题都附带改法：
- 有没有压到卡片、箭头字、箭头或页眉；
- 空白纸有多少（目标不超过 38%），最大的几块空地在哪；
- 有没有太实太重的色块；
- 有没有画出海报边；
- 哪一步插画完全没变；
- 人物比例对不对，脚是不是踩在同一条地面线上；
- 主题对比度和图钉颜色的意思对不对。

结果存在 `work/lint.json`。`scv.py posters` 会给每张海报多出一张 `NN-layout.png`，用蓝框画出排版的形状。

致谢：卡片画法、店面父状态、按线上色的条件、规则图例、聚光、显微镜和金线，都学自 Kevin Ngo 的 [statechart-art](https://github.com/kevintngo/statechart-art)（MIT），画法是我们自己写的。`pencil` 主题用了他的 Kevin Serif 和 Kevin Sans 字体（MIT，取自 A. V. Hershey 1967 年的公有领域字形）。
